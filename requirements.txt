# Development environment for LibEMG (Python 3.10+).
#
# Runtime dependencies live in pyproject.toml and are the source of truth for
# what `pip install libemg` pulls in. This file installs the library in
# editable mode plus the test and docs extras, so a contributor gets a working
# environment in one command:
#
#     pip install -r requirements.txt
#
# Previously this file pinned exact versions (scipy==1.7.2, matplotlib==3.5.0,
# websockets==8.1 and others). None of those publish wheels past cp310, which
# is what stopped the project installing on Python 3.11 and newer.

-e .[test,docs,torch]
